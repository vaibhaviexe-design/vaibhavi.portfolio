# MY STUDIO

Vaibhavi's interactive portfolio. Plain HTML, CSS and JavaScript: no build step.

## Publish on GitHub Pages (free)

1. Go to https://github.com and sign in (or create a free account).
2. Click the **+** at the top right, then **New repository**.
3. Name it, for example `my-studio`. Keep it **Public**. Click **Create repository**.
4. On the new repository page, click **uploading an existing file**.
5. Unzip this package on your computer. Open the unzipped `my-studio-site` folder and select everything inside it: `index.html`, `scene.js`, `content.json`, `.nojekyll`, and the `assets` and `video` folders. Drag them all into the GitHub upload area. (`index.html` must sit at the top level of the repository, not inside another folder.)
6. Wait for the upload to finish, then click **Commit changes**.
7. Open the repository's **Settings** tab, then **Pages** in the left menu.
8. Under **Build and deployment**, set **Source** to **Deploy from a branch**. Set **Branch** to `main` and the folder to `/ (root)`. Click **Save**.
9. Wait one to two minutes and refresh the Pages screen. The live link appears at the top: `https://YOUR-USERNAME.github.io/my-studio/`

## Notes

- Fonts load from Google Fonts, so visitors need an internet connection.
- To change text later, edit `index.html` (or `content.json` for the saved text overrides) on GitHub with the pencil icon, then commit.
- If the folders do not upload from a browser drag, GitHub's web upload accepts folders in Chrome, Edge and Firefox. Otherwise use GitHub Desktop.
